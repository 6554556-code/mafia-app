# Мафия с ИИ — версия для App Store (MVP)

Отдельный проект от сайта iplaymafia.com: своя папка, свой порт, своя база.
Задача — проверить, будут ли загрузки из App Store.

## Чем отличается от сайта
- **Никаких покупок**: нет ЮKassa, Ларька, VIP. Всё, что на сайте было VIP, — бесплатно всем
  (стол 8–12, выбор роли, путана и бомж, глаз бога, аватарки, досрочный выход).
- **Потолок — 20 партий в день** на игрока (`APP_GAMES_PER_DAY`) и 100 в день на адрес (`APP_IP_GAMES`).
- **Щиты**: 1 подарочный в день, не копится.
- **Гостевой вход**: только ник. Ни почты, ни пароля; cookie на год.
- Сайт закрыт от поисковиков (`robots.txt`), чтобы не дублировать iplaymafia.com.

## Где живёт
| | |
|---|---|
| Адрес | https://app.iplaymafia.com |
| Папка на сервере | `/root/mafia-app` |
| Порт | 3001 (`APP_PORT`) |
| База | `/root/mafia-app/mafia.db` (своя, с сайтом не связана) |
| Ключи | общий `~/.env` с сайтом (OpenRouter, Telegram) |
| Служба | `mafia-app.service`, сводка — `mafia-app-stats.timer` (12:05 МСК) |

## Команды
```
cd ~/mafia-app
git pull
systemctl restart mafia-app        # обрывает партии — в тихий момент
journalctl -u mafia-app -n 50      # логи
node stats.js                      # сводка
node stats.js online               # кто играет
```
